# Kalay -  Web Template

## Description
Kalay is a modern, high-contrast creative landing page template built from scratch using pure HTML5 and CSS3. The primary technical objective of this project was to implement a seamless full-screen media background overlay, handle center-axis content alignment, and construct standard information modules with strict adherence to fluid grid layout standards.

## Live Demo
Explore the live web template here:(https://nadaalafify.github.io/Kalay-Web-Template/)

## Tech Stack
- **HTML5:** Crafting semantic baseline structures, introductory text containers, and action navigation triggers.
- **CSS3 (Pure CSS):** Managing background image scaling layouts, alpha-channel color overlays, strict typography centering, and modern hover transition mechanics.

## Key Features and Technical Execution
- **High-Contrast Hero Overlay:** Implemented an exact color-masked background layout over full-width media to maintain rigorous text contrast and visual readability.
- **Symmetrical Information Architecture:** Managed exact spacing controls and baseline alignments for secondary content blocks below the fold.
- **Interactive Component Styling:** Configured smooth state changes for call-to-action modules using pure CSS transition timing properties.
- **Frameworkless Grid Design:** Developed 100% manually without relying on pre-built UI libraries to ensure structural control over component density and browser rendering optimization.
